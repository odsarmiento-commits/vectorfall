# VECTORFALL — Beta jugable

Proyecto 2D original creado en Godot 4.6 con GDScript y renderizador Compatibilidad.

## Contenido de la beta

- 4 agentes jugables, uno por arquetipo:
  - **VEKTOR — Asalto:** daño alto y Sobrecarga.
  - **AEGIS — Tanque:** mucha vida, armadura y escudos de equipo.
  - **LUMA — Apoyo:** curación grupal.
  - **FLUX — Control:** puede anular una fase enemiga.
- 5 niveles de campaña con geometrías y composiciones enemigas distintas.
- Enemigos Fragmento, Ariete, Rastreador, Centinela y jefe final Arconte Vectorial.
- Lanzamiento por arrastre, rebotes, combos, daño por velocidad, armadura y escudos.
- Progreso guardado en `user://vectorfall_progress.cfg`.
- Pruebas automáticas con Godot 4.6.3 en GitHub Actions.

## Controles

- **Ratón:** arrastra al agente activo hacia atrás y suelta para lanzar.
- **Espacio:** usa la habilidad del agente activo una vez por nivel.
- **Esc:** pausa/reanuda.
- **R:** reinicia el nivel.

## Campaña

1. Muelle Cero
2. Cámara Prisma
3. Pasarela Rota
4. Núcleo Magnético
5. Corona Vectorial

El proyecto no utiliza nombres, imágenes, música ni recursos de Hyper Heroes.
